# Лабораторна робота № 1-2

**Тема:** Поняття фреймворків як засобу для створення КІС.
**Мета:** Навчитися працювати з основами програмного коду фреймворку Node.js.

Проєкт знаходиться в каталозі `NodePIB` (перейменуйте на `Node<Ваше прізвище>`).

## Запуск

```bash
cd NodePIB
npm i          # встановити пакети з package.json
node index.js
```

| Файл | Пункт | Що робить |
|---|---|---|
| `package.json` | 12–16 | `type: module`, залежності chalk 5.6.2, path 0.12.7, os 0.1.2, fs 0.0.1-security, events 3.3.0, nodemailer 7.0.10; dev — nodemon |
| `index.js` | 8, 17–21 | Вивід `NUWM`, кольоровий вивід через chalk, прізвище, імпорт власного модуля |
| `data.js` | 20 | Власний модуль (`export default 'НУВГП'`) |
| `path.js` | 23 | `extname`, `parse` для поточного файлу |
| `os.js` | 26 | Інформація про ОС |
| `fs1.js` | 29 | Створення каталогу `PIB` |
| `fs2.js` | 31 | Створення `PIB/text.txt` і дописування тексту |
| `fs3.js` | 32 | Читання файлу як Buffer → рядок |
| `fs4.js` | 33 | Читання файлу в кодуванні utf-8 |
| `events.js` | 35 | EventEmitter + setTimeout |
| `program.js` | 37 | Каталог `logs`, файл `logs/events.txt`, подія `logEvent`, запис з датою, читання журналу |
| `mail.js` | 42 | Відправка листа через Gmail (nodemailer) |

Порядок запуску файлів fs: `fs1.js` → `fs2.js` → `fs3.js` / `fs4.js`.

## Результати виконання

```
> node events.js
Повідомлення: { a: 1 }
Повідомлення: { b: 2 }
Повідомлення: { c: 3 }
```
Синхронні `emit` виконуються одразу, а виклик у `setTimeout(..., 0)` — після завершення поточного стеку викликів.

```
> node program.js
Подія зареєстрована: Система запущена
Подія зареєстрована: Користувач увійшов
Подія зареєстрована: Дані збережено

Вміст журналу:
 [2026-11-17T19:53:47.698Z] Система запущена
[2026-11-17T19:53:47.698Z] Користувач увійшов
[2026-11-17T19:53:48.700Z] Дані збережено
```
(Перші два рядки «Подія зареєстрована» можуть виводитися в будь-якому порядку — `appendFile` асинхронний.)

## Відправка листа (п. 39–43)

1. Увімкніть двоетапну перевірку Google-акаунту.
2. Створіть пароль додатка «node.js»: https://myaccount.google.com/apppasswords
3. Запустіть (PowerShell):

```powershell
$env:MAIL_USER="ваш@gmail.com"; $env:MAIL_PASS="парольдодатка"; $env:MAIL_TO="отримувач@ukr.net"; node mail.js
```

Або впишіть дані напряму у `mail.js` замість `'user@gmail.com'` / `'пароль...'` (не комітьте пароль у репозиторій).

## Примітки

- Пакети `path`, `os`, `fs`, `events` встановлено з npm згідно із завданням, але Node.js завжди імпортує вбудовані модулі з такими іменами — код працює однаково.
- У прикладі п. 17 рядок `s1.rgb(34, 208, 95)(NUWM)` без лапок дає помилку `NUWM is not defined`; виправлено на `('NUWM')`.
- У `program.js` каталог створюється синхронно (`mkdirSync`), щоб він гарантовано існував до першого запису у файл.
